# 大商所"日成交持仓排名"原始文件(手动下载，一次性回填用)

- 文件名：`<合约代码>_<YYYYMMDD>.txt`，例 `M2701_20260901.txt`(合约代码取自文件名，文件内容里没有)。内容是大商所网站"日成交持仓排名"导出的文本(成交量/持买单量/持卖单量三张前20名榜)，原样保存。
- 用法：Actions → 回填历史数据 → only=`capital_rank`。把新下载的文件放进这个目录再点一次即可(幂等：已有日期不覆盖，数值不一致只在报告里记冲突)。
- 回填的是龙虎榜席位净持仓序列(高盛/摩根大通/瑞银/中粮/国投)，口径与线上每天累积的完全一致，见 `dce_rank_files.py`。

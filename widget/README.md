# 豆粕 iOS 桌面小组件（v101.82）

桌面显示：**当前交易合约实时价 + 涨跌 + 入场/观望/持仓/该平信号**。支持小/中/大三种桌面尺寸和锁屏三种尺寸。

## 安装（约 3 分钟，免费，不用 Mac、不用开发者账号）
1. App Store 搜索安装 **Scriptable**（免费）。
2. 把本仓库推送后，确认 GitHub Pages 已开、`data/widget.json` 能在浏览器打开：`https://xinzhenhua.github.io/DOUPO-Panel/data/widget.json`。
3. Scriptable → 右上角 **＋** 新建脚本 → 把 `widget/豆粕小组件.js` 的**全部内容**粘进去 → 取名「豆粕」。
   （用户名/仓库名/分支如果不是 `xinzhenhua / DOUPO-Panel / main`，改脚本最上面三行。）
4. 桌面长按空白处 → 左上角 **＋** → 选 Scriptable → 选尺寸 → 添加 → 长按小组件 → 编辑小组件 → **Script** 选「豆粕」。
5. 锁屏小组件：锁屏长按 → 自定义 → 添加小组件 → Scriptable → 同样选脚本。

## 显示什么
- 红涨绿跌（中国习惯）。大字 = 当前交易合约最新价，右上小字 = 报价时间和来源（东财/新浪/15分钟线）。
- 信号条：**观望**（灰）、**做多入场**（红）、**做空入场**（绿）、**持仓**（蓝，显示手数/浮盈%/浮盈元）、**该平：动作**（橙）、**数据不足**（灰，此时别按信号操作）。
- 中/大尺寸：入场信号时给「建议限价 / 止损价」；持仓时给开仓价和止损/移动止损线；大尺寸再加价格分位、外资最弱席位 5 日变化。

## 数据怎么来的（和驾驶舱同一份逻辑）
- `scripts/build_widget.js` 直接调用 `scripts/plan_alert.js` 的计算，生成 `data/widget.json`；交易时段每 5 分钟（update-prices）、基本面更新时（update-data）各生成一次。
- 小组件打开时再直连东方财富取一次实时价（失败换新浪，再失败用 widget.json 里的 15 分钟线）。
- 持仓来自 `data/position.json`（Actions「记录持仓」写入的那份），小组件不需要密码、不写任何数据。

## 要知道的限制
- **不是逐秒跳动**：iOS 决定小组件多久刷新（交易时段通常 5–15 分钟，低电量/长时间不看会更慢）。要最新价：点开小组件进驾驶舱，或在 Scriptable 里直接运行脚本。
- 小组件里的实时价是**当前交易合约**（和驾驶舱自动选的合约一致）；信号用的是换月调整后的主力连续价，所以「参考价」和实时价可以差几十点，这是正常的。
- 持仓合约和显示合约不一致时，浮盈用 Actions 算的值，不用实时价重算。
- 信号文件超过 45 分钟没更新（交易时段）会在小组件底部提示，去看 Actions 有没有在跑；节假日休市会显示「休市 / 报价较旧」。
- 信号按收盘后数据算，**入场挂限价单、平仓开盘市价都在下一个交易日**；小组件只是提醒，手数/止损/账户权益以驾驶舱为准。

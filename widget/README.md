# 豆粕 + 橡胶 iOS 桌面小组件（v102.8）

桌面显示：**当前交易合约实时价 + 涨跌 + 入场/观望/持仓/该平信号**。支持小/中/大三种桌面尺寸和锁屏三种尺寸。

## 安装（约 3 分钟，免费，不用 Mac、不用开发者账号）
1. App Store 搜索安装 **Scriptable**（免费）。
2. 把本仓库推送后，确认 GitHub Pages 已开、`data/widget.json` 能在浏览器打开：`https://xinzhenhua.github.io/DOUPO-Panel/data/widget.json`。
3. Scriptable → 右上角 **＋** 新建脚本 → 把 `widget/豆粕小组件.js` 的**全部内容**粘进去 → 取名「豆粕」。
   （用户名/仓库名/分支如果不是 `xinzhenhua / DOUPO-Panel / main`，改脚本最上面三行。）
4. 桌面长按空白处 → 左上角 **＋** → 选 Scriptable → 选尺寸 → 添加 → 长按小组件 → 编辑小组件 → **Script** 选「豆粕」。
5. 锁屏小组件：锁屏长按 → 自定义 → 添加小组件 → Scriptable → 同样选脚本。

## 显示什么
- 红涨绿跌（中国习惯）。大字 = 当前交易合约最新价，右上小字 = 报价时间和来源（东财/新浪/15分钟线）。
- 信号条：**观望**（灰）、**做多入场**（红）、**做空入场**（绿）、**持仓**（蓝，显示手数/浮盈%/浮盈元）、**该平：动作**（橙）、**数据不足**（灰，此时别按信号操作）。
- 中/大尺寸：入场信号时给「建议限价 / 止损价」；持仓时给开仓价和止损/移动止损线；大尺寸再加价格分位、外资最弱席位 5 日变化。

## 数据怎么来的（和驾驶舱同一份逻辑）
- `scripts/build_widget.js` 直接调用 `scripts/plan_alert.js` 的计算，生成 `data/widget.json`；交易时段每 5 分钟（update-prices）、基本面更新时（update-data）各生成一次。
- 小组件打开时再直连东方财富取一次实时价（失败换新浪，再失败用 widget.json 里的 15 分钟线）。
- 持仓来自 `data/position.json`（Actions「记录持仓」写入的那份），小组件不需要密码、不写任何数据。

## 要知道的限制
- **不是逐秒跳动**：iOS 决定小组件多久刷新（交易时段通常 5–15 分钟，低电量/长时间不看会更慢）。要最新价：点开小组件进驾驶舱，或在 Scriptable 里直接运行脚本。
- 小组件里的实时价是**当前交易合约**（和驾驶舱自动选的合约一致）；信号用的是换月调整后的主力连续价，所以「参考价」和实时价可以差几十点，这是正常的。
- 持仓合约和显示合约不一致时，浮盈用 Actions 算的值，不用实时价重算。
- 信号文件超过 45 分钟没更新（交易时段）会在小组件底部提示，去看 Actions 有没有在跑；节假日休市会显示「休市 / 报价较旧」。
- 信号按收盘后数据算，**入场挂限价单、平仓开盘市价都在下一个交易日**；小组件只是提醒，手数/止损/账户权益以驾驶舱为准。

## v102.8：橡胶也进小组件（同一个小组件里自动切换品种）
**重新粘贴脚本**：Scriptable 里把 `widget/豆粕小组件.js` 的全部内容替换进原来的脚本（脚本名不用改，桌面小组件不用重加）。
显示规则（每次刷新时判断）：
1. **有「要处理」的优先弹出**：入场信号（豆粕做多/做空入场、橡胶做空信号）、该平（豆粕该平、橡胶止损/3月最后交易日/出现离场条件）。
2. 没有要处理的，**有持仓的优先**显示。
3. 都没有 → **豆粕**。
4. 同一档里有两个（同时有信号、或同时持仓）→ **轮换**，每 5 分钟换一个；小组件下方一行小字写「另：…」说明另一个品种现在的状态。
- 橡胶持仓来自驾驶舱记的空单（`data/account.json` 的 `ruTrades`，和豆粕同一个账户文件）；记完单后最多等下一次 5 分钟更新才会出现在小组件里。
- 橡胶信号用的是和页面同一份规则，天气**不拦单**（v102.9 起驾驶舱里也一样，天气只显示在页面上）；需求爆发/政策/低产共振这些自动拦单条件是包含的。
- 橡胶实时价取上期所 RU 主力（东财，失败换新浪，再失败用日线收盘）；休市时显示「休市」。非3月橡胶没有信号也没有持仓时，小组件仍显示豆粕。

## v102.13：小组件改版（逐条打勾、外资线、状态统一、锁屏状态点）
**需要两步**：① 先把本次提交合并到 main，等 Actions 跑一次（交易时段 5 分钟内；`data/widget.json` 会升到 v3，带逐条条件）；② Scriptable 里把 `widget/豆粕小组件.js` 全部内容替换进原脚本（脚本名、桌面小组件都不用重加）。只做第②步也能用，但没有打勾表（退回一句话原因）。
- **大号**：做多 4 条、做空 3 条逐条 ✓/✗ + 当前值（✗ 加粗橙色，一眼看出差哪条）；外资行写「最弱席位 5 日变化 / 去杠杆线 −20,000（距线还差 N 手）」；原来重复的「价格分位」一句删了。
- **中号**：左价格+信号条，右侧打勾表（显示更接近触发的那一边：做多或做空）；底部一行外资线。
- **小号**：补一句为什么观望（如「分位87% 不在低位（需≤50%）」）；底部写数据日期。
- **外资线**：最弱席位 ≤ −14,000 手（线的 70%）变橙色提醒，到 −20,000 即去杠杆（做多被拦、做空触发条件之一）。
- **状态词统一**（三种尺寸一致）：休市 =「休市·收盘 23:00」（灰）；取不到信号文件、用手机缓存 =「离线·缓存 HH:MM」（橙）；盘中报价超过 15 分钟没动 =「报价较旧」（橙）。取信号文件改为两个地址各试两轮，减少误报离线。
- **橡胶**：休眠（非 3 月、无持仓）时整行隐藏；出做空信号/有持仓时才弹出。
- **锁屏**：矩形三行（价格 / 涨跌+状态 / 状态点+结论+分位）；状态点：🟢 数据齐·观望　🟠 数据缺失/过期/离线　🔴 有入场信号或该平　🔵 持有中。行内、圆形也带状态点。
- 数据：`widget.json` v3 新增 `signal.chk`（逐条条件）、`signal.fx`（外资线）、`signal.lv`（数据等级）、`signal.warn`；文件仍 <2KB。条件顺序/标签见脚本里 `CHK_LONG / CHK_SHORT` 与 `build_widget.js` 的 `buildChecks()`，两处必须一致。
- 没做：实时走势图、持仓盈亏的新来源（仍读 `data/position.json`，须及时记录）。

- **v102.13b 补丁**：旧版 `widget.json`（v2，没有逐条条件）也画打勾表：分位、外资两条用真实数据，反弹确认/期货≤现货标「待更新」；大号用弹性间距把内容撑开、不留底部空白，价格放大到 44pt。Actions 重新生成 v3 后「待更新」自动变成真实 ✓/✗。

## v102.13c：小号/中号/大号按「最可能出信号」精简 + 基本面 + 橡胶休眠状态
- **只显示最接近出信号的那一边**（做多 或 做空，按满足条数占比；已出信号的那边优先）；另一边只在标题里写进度，如「做空 2/3　做多 2/4」。小号、中号用页面同款小标签（✓ 绿 / ✗ 黄）：`✗去杠杆 ✓MA20 ✓高位87%`；大号用逐条行（带当前值）。
- **小号**：价格+涨跌幅一行；信号条带「空2/3」；两行小标签；页脚「橡胶休眠 · 刷新 HH:MM」。
- **中号**：右栏 = 最接近那边的小标签 + 基本面两行（基本面/结构、技术/综合）；底部外资线；页脚「橡胶休眠·距3月开窗N天 · 数据日 · 刷新」。
- **大号**：最接近那边的逐条打勾 + 外资线（距去杠杆线还差N手）+ 基本面块（供需票数、结构、技术、综合倾向与置信度）+ 橡胶一行（休眠时写「下一个窗口 2027-03-01（还有N天）」）。
- **锁屏**：第三行「🟢 观望 空2/3 差去杠杆」——直接说差哪条。
- **基本面来源**：`data/widget.json` v4 新增 `fund`，取自 `data/history/systems_<合约>.json` 最后一条（Actions 每小时用驾驶舱同一份评分引擎记录的系统方向，不是小组件自己算的）。文件缺失就不画这块。旧 v2/v3 文件：打勾表照常（旧文件用合成条件），基本面块不显示，等 Actions 重新生成 v4。
- 橡胶出信号/持仓时，橡胶那一行自动变蓝并显示「橡胶：做空入场」等，不再是灰色休眠。
